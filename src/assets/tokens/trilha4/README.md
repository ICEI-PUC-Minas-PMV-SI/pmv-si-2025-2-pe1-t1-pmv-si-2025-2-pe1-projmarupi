# Trilha 4 Token Images

Place your token images in this folder.

## Token Files Needed:
- `token_easy_win.png` - Win on Easy mode
- `token_hard_win.png` - Win on Hard mode
- `token_speed.png` - Win in less than 1 minute
- `token_efficient.png` - Win in 20 movements or less

## Image Requirements:
- Format: PNG
- Recommended size: 100x100 pixels
- Transparent background recommended

The game will automatically award these tokens when players achieve the corresponding goals.
