Perguntas Frequentes

O que é a Plataforma Marupí?
É um ambiente digital gamificado que incentiva crianças e jovens a explorarem o mundo real por meio de trilhas de aprendizado conectadas à sua comunidade.
Preciso pagar para usar?
Não. O acesso é gratuito para alunos e educadores, com possibilidade de expansão futura para módulos avançados.
Como funcionam os tokens?
Cada atividade concluída rende tokens virtuais, que podem ser usados para desbloquear novas trilhas ou conquistas dentro da plataforma.
É acessível para alunos neurodivergentes?
Sim. A plataforma foi projetada com baixo estímulo visual, linguagem simples e atividades curtas para atender diferentes perfis de aprendizagem.
Professores podem usar em sala de aula?
Sim. O sistema oferece relatórios de desempenho e sugestões de atividades que podem ser integradas ao currículo escolar.
