IBGE - Instituto Brasileiro de Geográfia e Estatísticas.

API de serviço de dados do IBGE - "Dados Agregados"

Para uso no desenvolvimento de aplicações, a ferramenta disponibiliza dados de pesquisas e censos realizados pelo IBGE. Permite que sistemas e aplicações recebam dados estatísticos de forma automatizada. Os usuários podem construir consultas complexas especificando parâmetros como o tipo de pesquisa, o período de tempo, o nível geográfico (por exemplo, município, estado) e as variáveis de interesse.

PIB - Api Agregados

Os dados sobre a informação de PIB são do censo de 2012, e devem ser considerados para fins de estimativa.

Worldometer

Fornece estatísticas mundiais em tempo real sobre uma ampla variedade de tópicos, como população, economia, saúde e meio ambiente. Os números são apresentados em contadores dinâmicos que se atualizam constantemente, dando uma noção da magnitude das mudanças globais em curso. "O Worldometer é administrado por uma equipe internacional de desenvolvedores, pesquisadores e voluntários com o objetivo de disponibilizar estatísticas mundiais em um formato instigante e relevante em termos de tempo para um amplo público em todo o mundo[...]"
